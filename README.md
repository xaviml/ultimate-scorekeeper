# Ultimate Scorekeeper

A Progressive Web App for keeping score at Ultimate Frisbee games — designed for **scorekeepers who don't necessarily know the sport**. A persistent assistance bar tells the scorekeeper exactly what to say and which hand signal to use at every stage of the game, so no prior Ultimate experience is needed to run a match.

Works on any device with a browser, installs to the home screen, and keeps working without an internet connection.

## Features

- **Guided scorekeeping**: step-by-step prompts with hand-signal pictures, so the scorekeeper always knows what to announce and when.
- **Easy setup**: configure divisions, team names and colors, gender-ratio rules, coin-toss results, target scores, time limits, cap rules, timeouts and break durations.
- **Simple scoreboard**: big tap zones to score (tap = +1, long-press = undo), live clocks for the game and for the pull/timeout/half-time, and quick access to timeouts, injuries, spirit-of-the-game pauses and half-time.
- **Built-in safeguards**: prevents scoring at the wrong moment, keeps scores from going negative, and undo restores everything correctly.
- **Audio alerts**: whistle sounds mark pull time milestones, timeout endings and caps.
- **Post-game report**: final score, game stats and a full event history, ready to copy and share.
- **Multiple languages**: available in English, Spanish and Catalan, matching the device's language automatically.
